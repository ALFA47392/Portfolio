# Mon Portfolio Professionnel

Bienvenue sur le dépôt de mon portfolio personnel. Ce projet centralise mes réalisations, mes compétences techniques et mon parcours de formation. Il sert d'interface vitrine pour présenter mes projets de développement web et logiciel.

## 🚀 Objectifs
* **Présentation de Projets :** Galerie interactive de mes réalisations (GitHub & Démos).
* **Curriculum Vitae Digital :** Détail de mes expériences et formations.
* **Formulaire de Contact :** Système de mise en relation directe.
* **Responsive Design :** Expérience utilisateur fluide sur mobile, tablette et desktop.

## 🛠️ Stack Technique
* **Frontend :** HTML5 / CSS3 (Modern layouts)
* **Dynamisme :** JavaScript (ES6+) pour les animations et la navigation.
* **Performance :** Optimisation des assets et du temps de chargement.
* **Déploiement :** [Précisez : GitHub Pages / Vercel / Netlify]

## 📂 Architecture
* `images/` : Ressources graphiques, icônes et CV (PDF).
* `css/` : Feuilles de style (Design system, Media Queries).
* `js/` : Gestion du menu mobile, des filtres de projets et des animations.
* `index.html` : Structure sémantique du site.
